# AtlANTian documentation

Each document owns one topic. Operational instructions should live in the owning document and be linked elsewhere instead of copied.

- [QUICKSTART.md](QUICKSTART.md) — write the SD image, boot, find the board and log in.
- [INSTALLATION.md](INSTALLATION.md) — install the current release from SD to on-board NAND.
- [UPGRADING.md](UPGRADING.md) — update SD or NAND installations and recover interrupted updates.
- [NAND.md](NAND.md) — NAND boot/storage architecture, ECC, UBI and maintenance transaction design.
- [PERSISTENCE.md](PERSISTENCE.md) — what is writable and what survives updates in each storage mode.
- [hardware-support-matrix.md](hardware-support-matrix.md) — implemented hardware interfaces and source locations.
- [HARDWARE-VALIDATION.md](HARDWARE-VALIDATION.md) — commands and acceptance checks for a physical board.
- [PIPELINE.md](PIPELINE.md) — build graph, CI gates, release artifacts and GitHub automation.
- [DEBIAN-LIFECYCLE.md](DEBIAN-LIFECYCLE.md) — Debian Snapshot, runtime APT and upstream refresh policy.
